# Расшифровка капчи
Данная программа (main.py), расшифровывает капчи, которые располагаются в директории (img)
Данная программа использует для обработки изображения и обнаружение контуров OpenCV и для определения символов - pytesseract.

Пользовательский интерфейс реализован в файле ui_main.py

Расшифровка капчи проходит следующие этапы для расшифровки капчи
Этап 1: Обработка изображения
1. Захват изображения. Изображение дополнительно масштабируется для лучшего считывания контуров
2. Преобразования изображения в серый цвет с помощью .
3. Бинаризация изображения с помощью cv2.threshold
4. Размытие изображения с помощью cv2.medianBlur
5. Операция "Эрозия" с помощью команды cv2.erode
6. Операция "Раскрытие" (удаление шума) с помощью команды cv2.morphologyEx (с параметром cv2.MORPH_OPEN)

Этап 2: Обработка контуров
1. Идет считывание контуров
2. Идет фильтрация контуров. Если контур меньше определенного значения, контур закрашивается черным.

Этап 3: Распознание контуров символов
Процесс распознавания контуров происходит с помощью команды pytesseract

Результат
Данная программа хорошо распознает капчу, которая располагается в папке img. Однако, у данной программы возникают проблемы с распознаванием символов, когда они очень сильно наклонены. Это происходит из-за того, что tesseract не может распознавать данные символы
Возможные решения
Создания отдельной базы символов, на основе которой программа могла обучится распознаванию (например TensorFlow)
